# Rule-Based AI Chatbot 🤖

This project was developed for the DecodeLabs AI Internship.

## Features
- Rule-based responses
- Greetings handling
- Exit commands
- Continuous conversation loop
- Streamlit user interface

## Technologies Used
- Python
- Streamlit

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
```
